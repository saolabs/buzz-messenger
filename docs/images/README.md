# README images

- `logo.svg`: the current app icon, copied from `resources/ym/icon.svg` so README rendering doesn't depend on ignored runtime files.
- `buddy-list-en.png`, `chat-en.png`, `login-en.png`: English interface screenshots.
- `buddy-list-vi.png`, `chat-vi.png`, `login-vi.png`: Vietnamese interface screenshots.

Screenshots were captured from the app renderer with the Purple skin at 125% zoom. Contacts and conversations are sample data; no Facebook account was connected. They illustrate the interface, not a live messaging session.

The logo is derived from the Yahoo installer artwork with a B in place of the Y. Screenshots include Yahoo skin and emoticon artwork. Their inclusion here doesn't change the assets' origin or grant a separate license; see the [README credits](../../README.md#credits-and-assets).
